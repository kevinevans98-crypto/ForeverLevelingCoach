# Alpha tester recruitment kit

**Do not recruit with a download link until an alpha build has passed syntax checks, a clean install, and an in-game smoke test.**

## Recruitment post (copy and customize)

**Volunteer Alpha Testers Wanted — Forever Leveling Coach (WoW Forever Beta)**

I'm developing Forever Leveling Coach, a free beginner-friendly leveling addon. I'm preparing a small alpha test to improve multi-quest routing, verified waypoints, quest tracking, and class guidance.

I'm looking for 5 volunteer players across Horde and Alliance starting zones. New players are welcome. Testing takes about 20–30 minutes per session, and you'll use a simple in-addon **Report** button to prepare feedback for GitHub.

This is an experimental alpha, not a finished or officially endorsed WoW Forever addon. Please back up your addon settings before testing. Reports are manually submitted and should be reviewed for private character information.

If interested, reply with your **class, faction, starting zone, and approximate playtime availability**. No account credentials or personal information needed. I'll share the verified build and instructions when ready.

— LilGoob Gaming

## Recruitment and release checklist

- [ ] Verify the alpha build loads without errors.
- [ ] Publish a clear alpha version/build identifier and ZIP checksum.
- [ ] Confirm Report button and /flc report in-game.
- [ ] Test the GitHub issue form and triage workflow.
- [ ] Get permission from Discord/community moderators before recruiting or posting download links.
- [ ] Recruit five volunteers; assign zones to maximize coverage.
- [ ] Collect one issue per reproducible problem; triage duplicates weekly.
- [ ] Avoid promises of paid rewards, data privacy guarantees, or full class support.
